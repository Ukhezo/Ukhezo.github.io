About Me

Developer, designer and lifelong learner

I'm a first-year BSc Computing student at the University of South Africa (UNISA) and I hold the FNB App Academy Certificate in Full Stack Development (2025). I've built web apps with HTML, CSS and JavaScript, built and used APIs, and I manage all my code in Git and GitHub.

My projects go beyond code: I designed a mobile banking app for first-time digital bankers in rural KwaZulu-Natal, built a full front-end clothing store, and turned local election results into editorial infographics. I write small Python tools to generate pages, check links and keep data accurate.

I work full time during the day while carrying a full UNISA module load, so I manage my own schedule, meet deadlines and work independently. I'm looking for a remote internship where I can contribute to real code alongside experienced developers.
